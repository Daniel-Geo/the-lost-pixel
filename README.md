# the-lost-pixel
**A small creature lost in the void needs to find treasures located in a far land**  
​Move with WASD or the arrow keys.  
You can also jump with the spacebar.  
Fire a magical spell projectile with X or L keys after you acquire the spell in the second level.  
Dash to reach new lands with the C key after acquiring it in the third level.  
Wall jump like a hunter (acquired in the fourth level).  
Double jump like a pro (acquired in the fifth level).​  
Jump upside-down using the new gravity boots (acquired in the sixth level).  
Create your own levels from scratch using the in-game level editor.
